Lab 7 — Binary Trees

Before you start

Clone the assignment repository from GitHub Classroom (link on the course page). Do all work there, not in a scratch file — the autograder runs against that repository’s structure.

Part A (20 min) — Warm-up: traversals and height

Implement preorder, inorder, postorder, and level_order exactly as in Lecture 1, and tree_height from Lecture 1’s exercise. Build the six-node example tree from Lecture 1 and confirm all four traversals and the height match the lecture’s stated results exactly.

Part B (60 min) — BST with search, insert, delete

Implement bst_search, bst_insert, and bst_delete (all three cases) exactly as in Lecture 2. Then:

  • Insert [5, 3, 8, 1, 4, 7, 9] into an empty BST and confirm inorder produces the sorted sequence.
  • Delete the root (a two-children case) and confirm the resulting tree still satisfies the BST property (write a is_valid_bst checker using the min/max range technique from Lecture 2’s “common mistake” slide, not a naive immediate-parent check).
  • Delete a leaf and a one-child node, confirming each reduces correctly.

Part C (20 min) — Challenge: AVL insertion with rotations

Implement AVL insertion (balance factor tracking plus all four rotation cases from Lecture 3). Insert [1, 2, 3, 4, 5, 6, 7] and confirm the final tree height is 2, matching Lecture 3’s exercise exactly — then insert the same sequence into a plain (non-AVL) BST from Part B and confirm its height is 6, demonstrating the contrast directly.

MTech addition

Implement range_query, floor, and ceiling exactly as in Lecture 4. Then implement the augmented subtree_size-tracking node and select_kth from Lecture 4’s MTech addition, and confirm it correctly finds the median (the \(\lfloor n/2 \rfloor\)-th smallest element) of a BST built from 99 random values, cross-checking against sorted(values)[49].

On Your Own (Optional, Ungraded)

This part is optional and ungraded. It is not submitted, not part of the autograder, and not assessed in any way — it exists purely as extra practice if you want to go further with this week’s material after the graded lab tasks are done. There is no deadline attached to it.

Implement is_balanced(root) for a general (not necessarily BST) binary tree, returning True only if, for every node, the heights of its left and right subtrees differ by at most 1 — and do it in a single O(n) traversal rather than recomputing height at every node (which would be O(n log n) or worse). Frame this as a health-check utility a production tree-backed index might run periodically to detect whether an AVL invariant has silently drifted.
