Course Learning Outcomes (CLO1–CLO6)

  1. CLO1: Analyze the time and memory cost of algorithms using Big-O notation, recurrences, and amortized analysis.
  2. CLO2: Implement arrays, stacks, queues, linked lists, trees, hash tables, heaps, and graphs from first principles in Python.
  3. CLO3: Prove algorithm correctness using loop invariants and exchange arguments, and reason about lower bounds such as sorting's $\Omega(n \log n)$ bound.
  4. CLO4: Design efficient solutions using sorting, recursion, dynamic programming, greedy algorithms, and graph search.
  5. CLO5: Evaluate empirical performance by profiling, benchmarking, and choosing data structures backed by experimental evidence.
  6. CLO6: Apply data structures and parallel or randomized methods to large real datasets, including Zanzibar routing and agricultural pricing workloads.

Course Policies

Attendance
Attendance is expected at all four weekly lectures and Thursday labs. Bring a charged laptop to class and complete weekly labs before the session ends.
Late Work
Late submissions lose 10% per day and are not accepted after 3 days. For documented emergencies, contact Dr. Nyalala before the deadline.
Academic Integrity
Discussing ideas with classmates is encouraged; sharing or copying code is prohibited. Every submitted line must be code you can trace and explain orally.
Use of AI Tools
AI coding assistants may be used to clarify concepts and inspect error messages, not to generate submitted lab solutions, ICA code, or written proofs.
