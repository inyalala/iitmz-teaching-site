Big Data Lab

Learning Outcomes

  1. Deploy a Docker-based big data environment and run end-to-end PySpark jobs, explaining the Spark execution model, DAG stages, and Spark UI metrics.
  2. Build and manage Delta Lake and Apache Iceberg tables with ACID transactions, time travel, schema evolution, and partition evolution.
  3. Write complex PySpark SQL queries and window functions over large datasets, and profile and fix performance bottlenecks using Adaptive Query Execution.
  4. Orchestrate batch Spark workloads using Apache Airflow DAGs and Dagster pipelines with dependency management and scheduling.
  5. Build real-time streaming pipelines with Apache Kafka and Spark Structured Streaming, implementing watermarks, window aggregations, and exactly-once semantics.
  6. Create live observability dashboards with Grafana and Prometheus, and deploy interactive data applications with Streamlit.
  7. Train and tune distributed ML models with Spark MLlib and Ray, tracking experiments and registering models with MLflow.
  8. Package and deploy ML models as production REST APIs using BentoML and Docker, with monitoring and data lineage via OpenLineage.

Infrastructure
All labs run on a Docker Compose environment provided at the start of the course. Students run everything locally or on lab machines; no cloud account required.

Policies

Attendance
Attendance is mandatory at all lab sessions. Lab work is submitted before the session ends; the hands-on practice cannot be replicated outside the structured session.
Late work
Late work is not accepted. Deadlines are fixed and announced in advance; submit what you have by the deadline. No extensions.
Academic integrity
Discussing approaches is encouraged; submitting another student's code is not. Every notebook you submit must reflect your own work, which you can explain and extend. Declare any material AI contribution in a notebook header cell.
