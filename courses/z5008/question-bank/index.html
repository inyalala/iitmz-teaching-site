Lab 1

Big Data Landscape & Setup

Q1EasyQuiz

Define the three Vs of Big Data (Volume, Velocity, Variety). Give a concrete example of a dataset that scores high on all three.

Q2EasyAssignment

What is the difference between a data lake, a data warehouse, and a lakehouse? In what scenario would you choose each?

Q3EasyQuiz

What does the Spark UI show you? Name three pieces of information you can extract from a Spark job's DAG visualisation.

Q1IntermediateQuiz

Explain the difference between Spark's driver and executor roles. What happens when an executor fails? How does Spark's fault tolerance model handle this?

Q2IntermediateAssignment

Write a PySpark job that reads a CSV file, filters rows where sales > 1000, groups by region, computes the total and average sales per region, and writes the result to a Delta Lake table.

Q1AdvancedExam

Compare the Hadoop MapReduce and Apache Spark execution models. Why is Spark typically 10–100× faster for iterative workloads? Under what conditions does MapReduce outperform Spark?

Lab 2

Lakehouse & Delta Lake

Q1EasyQuiz

What ACID properties does Delta Lake provide on top of a plain Parquet data lake? How does it achieve atomicity for multi-file writes?

Q2EasyAssignment

What is Delta Lake's time travel feature? Write a PySpark snippet to read a Delta table as it existed 3 versions ago.

Q1IntermediateQuiz

Explain the Delta Lake MERGE (UPSERT) operation. Write a PySpark MERGE statement that inserts new customer records and updates the email address for existing customers based on customer_id.

Q2IntermediateAssignment

What is Delta Lake's transaction log (_delta_log)? How does it differ from a traditional write-ahead log? What information does each JSON file in the log contain?

Q1AdvancedExam

A Delta Lake table receives 10,000 small file writes per hour. Explain the "small files problem" and its performance impact. What Delta Lake operations (OPTIMIZE, Z-ORDER, VACUUM) would you schedule and at what frequency to maintain query performance?

Lab 3

Apache Iceberg & Data Governance

Q1EasyQuiz

What is Apache Iceberg? Name two features that distinguish it from a plain Parquet-based data lake.

Q2EasyAssignment

What is partition evolution in Iceberg? Why is it important for long-lived production tables?

Q1IntermediateQuiz

Explain schema evolution in Iceberg. What operations (add column, rename column, drop column) are supported without rewriting data? What is the role of field IDs in making this safe?

Q2IntermediateExam

Compare Delta Lake and Apache Iceberg across: ACID support, schema evolution, partition evolution, engine support, and catalog integration. For a multi-engine lakehouse (Spark + Flink + Trino), which would you choose and why?

Q1AdvancedProject

Design a data governance framework for a lakehouse serving both a regulatory reporting team (needs lineage, audit, immutability) and a data science team (needs fast iteration, schema flexibility). How do you balance these competing needs using Iceberg, Nessie Catalog, and OpenLineage?

Lab 4

Spark Foundations & DataFrame API

Q1EasyQuiz

What is the difference between a Spark transformation and an action? Give two examples of each. Why does Spark use lazy evaluation?

Q2EasyAssignment

What is a Spark partition? How does the number of partitions affect parallelism and performance? What is the recommended partition size in MB?

Q3EasyQuiz

Explain the difference between cache() and persist() in Spark. When should you cache a DataFrame?

Q1IntermediateAssignment

Write PySpark code to: read a JSON dataset of e-commerce orders, explode a nested items array, compute total revenue per product category, and write the output as a partitioned Parquet file partitioned by category.

Q2IntermediateQuiz

What is the difference between map() on an RDD and select() on a DataFrame? When would you prefer the RDD API over the DataFrame API?

Q1AdvancedExam

A Spark job reads a 500 GB Parquet file and runs a groupBy aggregation. The job has 200 tasks in stage 1 and 200 tasks in stage 2, but stage 2 takes 10× longer with a few tasks running much longer than others. Diagnose this problem and propose three specific remedies.

Lab 5

Spark SQL, Joins & Window Functions

Q1EasyQuiz

What are the two physical join strategies Spark uses? When does Spark automatically choose a broadcast join?

Q2EasyAssignment

Write a Spark SQL window function query to compute each employee's salary rank within their department, using RANK(). How does RANK() differ from DENSE_RANK()?

Q1IntermediateQuiz

Explain what a shuffle join is in Spark. Why is it expensive? How does a sort-merge join differ from a hash join, and when does Spark prefer each?

Q2IntermediateAssignment

Using a transactions table with columns (txn_id, user_id, amount, txn_date), write Spark SQL to compute: (a) 7-day rolling average amount per user, (b) cumulative total amount per user ordered by date, (c) each transaction's percentage contribution to the user's monthly total.

Q1AdvancedExam

You are joining a 500 GB fact table with a 200 MB dimension table. Explain two strategies: (a) broadcast join, (b) bucketed join. For each, describe how to implement it in PySpark, its memory requirements, and when it is preferable. What happens if you try to broadcast a 5 GB table?

Lab 6

Spark Performance Tuning & AQE

Q1EasyQuiz

What is data skew in Spark? How can you detect it in the Spark UI? Name two techniques to fix it.

Q2EasyQuiz

What is Adaptive Query Execution (AQE) in Spark 3? Name three optimisations it can apply at runtime that the static query planner cannot.

Q1IntermediateAssignment

A Spark job joining two large tables runs for 4 hours. You observe in the Spark UI that 5 of 200 tasks take 90% of the time, and the join key is country_code with 70% of rows having country_code = 'TZ'. Propose and implement a salting strategy to fix this skew.

Q2IntermediateQuiz

Explain the impact of the following Spark configuration parameters: spark.executor.memory, spark.executor.cores, spark.sql.shuffle.partitions. What values would you start with for a cluster with 10 nodes, 16 cores each, and 64 GB RAM per node?

Q1AdvancedExam

Profile a Spark job end-to-end: describe the metrics you would examine in the Spark UI (stages, tasks, GC time, shuffle read/write, spill) to identify whether the bottleneck is CPU-bound, memory-bound, I/O-bound, or network-bound. For each bottleneck type, prescribe specific configuration changes and code changes.

Lab 7

Data Orchestration

Q1EasyQuiz

What is an Airflow DAG? What do nodes and edges represent? What happens if an Airflow DAG has a cycle?

Q2EasyAssignment

What is the difference between Airflow and Dagster in terms of their data model? How does Dagster's asset-based approach differ from Airflow's task-based approach?

Q1IntermediateAssignment

Write an Airflow DAG (in Python) that: (1) extracts data from an API daily at 06:00 UTC, (2) runs a Spark job to transform it, (3) loads the result to a Delta Lake table, (4) sends a Slack alert if any task fails. Include retry logic and timeouts.

Q2IntermediateExam

Explain Airflow's XCom mechanism. What are its limitations for large data? What alternative patterns exist for passing data between tasks in a production pipeline?

Q1AdvancedProject

Design a production data pipeline orchestration strategy for a financial reporting system that must: process 50 GB of daily transaction data, complete within a 4-hour SLA, handle partial failures gracefully with idempotent reruns, and maintain a full audit log. Compare Airflow vs Dagster for this use case.

Lab 9

Kafka & Real-Time Streaming

Q1EasyQuiz

Define: Kafka topic, partition, offset, producer, consumer group. Explain how consumer groups enable both load balancing and message broadcasting.

Q2EasyAssignment

What guarantees does Kafka provide regarding message ordering? Are messages ordered globally across all partitions or only within a partition?

Q3EasyQuiz

What is Redpanda? How does it differ from Apache Kafka architecturally (no ZooKeeper/KRaft dependency)?

Q1IntermediateAssignment

Write a Python Kafka producer that publishes JSON sensor readings (temperature, humidity, device_id, timestamp) to a topic at 100 messages/second. Write a consumer that reads from the topic and writes batches of 1000 messages to a Delta Lake table.

Q2IntermediateExam

Explain the three delivery semantics in Kafka: at-most-once, at-least-once, and exactly-once. What producer and consumer configuration settings control each? What is the trade-off between exactly-once and throughput?

Q1AdvancedProject

Design a Kafka-based architecture for a real-time fraud detection system that processes 500,000 payment events per second. Specify: number of partitions and why, replication factor, retention policy, consumer group topology, and how you would handle a downstream consumer that is 10 minutes behind.

Lab 10

Spark Structured Streaming

Q1EasyQuiz

What is a watermark in Spark Structured Streaming? Why is it needed for window aggregations on event-time data?

Q2EasyAssignment

What are the three output modes in Spark Structured Streaming (Complete, Append, Update)? Which modes are compatible with aggregations and which with watermarks?

Q1IntermediateAssignment

Write a Spark Structured Streaming job that reads from a Kafka topic of clickstream events (user_id, page_id, event_time), applies a 5-minute tumbling window with a 2-minute watermark, counts clicks per page per window, and writes results to a Delta Lake table.

Q2IntermediateExam

Explain exactly-once semantics in Spark Structured Streaming. What role do checkpoints play? What happens to the stream state if the checkpoint directory is deleted?

Q1AdvancedProject

Design a stateful streaming pipeline that detects user sessions from a clickstream (a session ends after 30 minutes of inactivity). Discuss how to implement this using Spark's flatMapGroupsWithState or mapGroupsWithState. What are the memory implications of storing state for 10 million concurrent sessions?

Q1EasyAssignment

Q2EasyAssignment

What is Streamlit? How does it differ from a traditional web framework like Flask? When is it appropriate for a data engineer to use Streamlit?

Q1IntermediateExam

Lab 13

Distributed ML with Spark MLlib & Ray

Q1EasyAssignment

What is the MLlib Pipeline API? What are Transformers and Estimators? Give one example of each.

Q2EasyQuiz

What is Ray? How does it differ from Spark for distributed computing? What is Ray Tune used for?

Q1IntermediateAssignment

Write a Spark MLlib pipeline to train a classification model on a 10 GB customer churn dataset: include StringIndexer, VectorAssembler, and a RandomForestClassifier. Evaluate with cross-validation. How would you scale this to 1 TB?

Q2IntermediateExam

Explain distributed hyperparameter tuning with Ray Tune. What is the ASHA (Asynchronous Successive Halving Algorithm) scheduler? How does it reduce compute cost compared to grid search?

Q1AdvancedProject

Lab 14

MLOps with MLflow

Q1EasyAssignment

What are the four main components of MLflow (Tracking, Projects, Models, Registry)? Briefly describe what each does.

Q2EasyQuiz

What is a model registry? What lifecycle stages does MLflow's Model Registry support (Staging, Production, Archived)? Who should approve a model promotion to Production?

Q1IntermediateAssignment

Write Python code using the MLflow API to: log a training run (parameters, metrics, artifacts), register the resulting model, compare two model versions using logged metrics, and programmatically promote the better model to Production.

Q2IntermediateExam

Q1AdvancedProject

What metrics would you monitor post-deployment?

Lab 15

Model Deployment, Monitoring & Governance

Q1EasyAssignment

What is BentoML? What does "packaging a model" mean in the context of BentoML? What is a Bento?

Q2EasyQuiz

What is OpenLineage? What is data lineage and why is it important for regulated industries (healthcare, finance)?

Q3EasyAssignment

What is a Prometheus metric? Describe the four metric types (Counter, Gauge, Histogram, Summary) and give a Big Data example for each.

Q1IntermediateAssignment
