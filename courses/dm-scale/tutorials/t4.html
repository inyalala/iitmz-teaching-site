MapReduce &
Introduction to PySpark

pyspark · SparkContext · RDDs Submit as dm04t[RR].py
New library: PySpark. This is your first tutorial using PySpark. You need to install it before you start: pip install pyspark. PySpark requires Java (JDK 8 or 11). If you run into setup problems, come to office hours before the deadline.

Submission

Name your file dm04t[RR].py where RR = last two digits of your roll number. All tasks in one file with # Task N comments. Submit by the deadline announced in class.

Background

MapReduce is a programming model for processing large datasets in parallel. The Map step applies a function to each input record, emitting (key, value) pairs. The Reduce step groups by key and aggregates. PySpark is Apache Spark's Python API — it implements MapReduce-style processing through Resilient Distributed Datasets (RDDs), a fault-tolerant distributed collection. In this tutorial you will run Spark locally (one machine, multiple cores) and experience the RDD API before we scale to clusters.

We work with a small text dataset so you can trace every step by hand and verify the output.

Tasks

1

Start a SparkContext and Verify Setup

  1. Import: from pyspark import SparkContext, SparkConf
  2. Create a SparkConf for a local run:
    conf = SparkConf().setMaster("local[*]").setAppName("DM Tutorial 4") sc = SparkContext(conf=conf)
  3. Print the Spark version: print(sc.version)
  4. Print the default parallelism (number of local cores detected): print(sc.defaultParallelism)
Spark version: 3.x.x Default parallelism: [number of CPU cores on your machine]
"local[*]" tells Spark to use all available CPU cores on your machine. In production, you replace this with the cluster master URL.
2

Create an RDD and Explore It

We will use a list of sentences as our input dataset.

  1. Define:
    sentences = [ "data mining scales to large data", "large data needs distributed processing", "mapreduce splits data into map and reduce", "spark is faster than mapreduce for iterative jobs", "data streams require online processing algorithms" ]
  2. Create an RDD: rdd = sc.parallelize(sentences)
  3. Print the number of partitions: print(rdd.getNumPartitions())
  4. Print the first element: print(rdd.first())
  5. Print all elements: print(rdd.collect())
Partitions: [depends on cores] First: data mining scales to large data All: ['data mining scales to large data', 'large data needs distributed processing', ...]
3

Map Step — Tokenise Each Sentence

The Map step transforms each record. Here we split each sentence into (word, 1) pairs — the classic word count setup.

  1. Use flatMap to emit one (word, 1) pair per word across all sentences:
    pairs = rdd.flatMap(lambda sentence: [(word, 1) for word in sentence.split()])
  2. Print the count of pairs: print(pairs.count())
  3. Print the first 10 pairs: print(pairs.take(10))
Pair count: 37 First 10: [('data', 1), ('mining', 1), ('scales', 1), ('to', 1), ('large', 1), ('data', 1), ('needs', 1), ('distributed', 1), ('processing', 1), ('mapreduce', 1)]
flatMap vs map: map returns one item per input item; flatMap returns zero or more — it flattens lists from each call into one RDD.
4

Reduce Step — Count Words

  1. Group by key and sum: word_counts = pairs.reduceByKey(lambda a, b: a + b)
  2. Collect the results and sort by count descending
  3. Print the top 10 most frequent words
Top 10 words: data : 5 processing : 2 large : 2 mapreduce : 2 mining : 1 scales : 1 to : 1 needs : 1 distributed : 1 splits : 1
reduceByKey is the Reduce step — Spark automatically groups all (key, value) pairs with the same key and applies your function to combine values.
5

Filter — Words that Appear More than Once

  1. Filter the word_counts RDD to keep only words with count > 1: word_counts.filter(lambda x: x[1] > 1)
  2. Print these repeated words sorted alphabetically
Words appearing more than once: data : 5 large : 2 mapreduce : 2 processing : 2
6

Extension — MapReduce Pipeline on Numerical Data

Create a list of 1000 random integers between 0 and 99 using import random; nums = [random.randint(0, 99) for _ in range(1000)]. Parallelise into an RDD. Use map to label each number as "even" or "odd". Use countByKey() to count how many are even vs odd. Print the result. Then stop the SparkContext: sc.stop().

Don't forget sc.stop() at the very end of your script — leaving the SparkContext running keeps a web server alive on your machine.
