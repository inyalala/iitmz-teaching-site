Data Mining — Scaling to Large Data

Dr. Nyalala (Weeks 1–6)  ·  Dr. Mahendran V, IIT Tirupati (Weeks 7–15)  ·  3 Lectures + 1 Tutorial per week  ·  BS Programme

This is a 15-week course. Dr. Nyalala teaches Weeks 1–6 (ML basics, feature selection, ensembles, MapReduce, LSH, frequent patterns). Dr. Mahendran V (IIT Tirupati) teaches Weeks 7–15. This page covers Weeks 1–6 and all six tutorials.

Course Overview

Objective

Introduce students to techniques for mining large datasets. The course covers common data mining tasks and then approaches to scaling each of them to data that cannot fit in memory or on a single machine.

Primary Textbook

Mining of Massive Datasets
Rajaraman, Ullman & Leskovec
Cambridge University Press
Free PDF — mmds.org ↗

What You Already Know

Python, numpy, pandas, scikit-learn, basic probability and statistics, introductory machine learning, SQL and relational databases (DBMS). You do not need to know PySpark — introduced in Week 4.

Session Structure

3 lectures per week (typically Mon / Wed / Fri or as timetabled) plus 1 tutorial session per week. Tutorials are graded Python assignments submitted as .py files.

Learning Outcomes

  • Apply Bayesian Decision Theory and Maximum Likelihood Estimation to classification problems under uncertainty.
  • Select informative features using Information Gain and reduce dimensionality using PCA and LDA.
  • Handle class imbalance using sampling and loss-function approaches, and build ensemble classifiers (AdaBoost, Gradient Boosting, Random Forest).
  • Explain the MapReduce paradigm and write basic PySpark pipelines using RDD transformations and actions on real datasets.
  • Apply Locality-Sensitive Hashing to find approximate nearest neighbours in large collections, and compute PageRank using power iteration.
  • Implement the Apriori algorithm for frequent itemset mining and use Bloom Filters for approximate membership testing in data streams.
