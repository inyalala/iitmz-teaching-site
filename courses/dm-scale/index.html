Data Mining: Scaling to Large Data

Methods for scaling machine learning and mining algorithms to large datasets, covering Weeks 1 to 6 under Dr. Nyalala (Bayesian classification, feature selection, ensembles, MapReduce, PySpark, LSH, and frequent patterns) alongside Weeks 7 to 15 taught by Dr. Mahendran V (IIT Tirupati).

Lab 1 · Week 4
MapReduce with PySpark · RDD transformations, aggregations, and server log analysis.

Learning Outcomes

  1. Apply Bayesian Decision Theory and Maximum Likelihood Estimation to classification problems under uncertainty.
  2. Select informative features using Information Gain and reduce dimensionality using PCA and LDA.
  3. Handle class imbalance using sampling and loss-function approaches, and build ensemble classifiers (AdaBoost, Gradient Boosting, Random Forest).
  4. Explain the MapReduce model and write basic PySpark pipelines using RDD transformations and actions on real datasets.
  5. Apply Locality-Sensitive Hashing to find approximate nearest neighbours in large collections, and compute PageRank using power iteration.
  6. Implement the Apriori algorithm for frequent itemset mining and use Bloom Filters for approximate membership testing in data streams.
