Data Mining: Scaling to Large Data

Methods for scaling machine learning and pattern discovery to large datasets, co-taught with Dr. Mahendran V (IIT Tirupati): Weeks 1–6 core foundations and Part 1 modules (KDD, similarity, PCA, OLAP, Apriori/FP-Growth, Bayesian/tree classification, ensembles, and scalable clustering) under Dr. Innocent Nyalala, followed by Weeks 7–15 advanced topics under Dr. Mahendran V.

Learning Outcomes

  1. Apply Bayesian Decision Theory and Maximum Likelihood Estimation to classification problems under uncertainty.
  2. Select informative features using Information Gain and reduce dimensionality using PCA and LDA without data leakage.
  3. Handle class imbalance using sampling and threshold tuning, and build ensemble classifiers (AdaBoost, Gradient Boosting, Random Forest).
  4. Explain the MapReduce model and write PySpark pipelines using RDD transformations and actions on real datasets.
  5. Apply Locality-Sensitive Hashing to find approximate nearest neighbors in large collections, and compute PageRank using power iteration.
  6. Implement the Apriori algorithm for frequent itemset mining and use Bloom Filters for approximate membership testing in data streams.
