Module 01

ER Model & Foundations

Q1EasyQuiz

What is the difference between a strong entity and a weak entity in an ER diagram? Give one example of each.

Q2EasyQuiz

List the three types of attributes in an ER model and give an example of each.

Q3EasyICA

What is the purpose of a DBMS? Name two advantages of using a DBMS over flat-file storage.

Q4EasyQuiz

Define cardinality ratio in an ER relationship. What are the four possible cardinality ratios?

Q1IntermediateQuiz

Draw an ER diagram for a university database with entities Student, Course, and Instructor. Include appropriate attributes, primary keys, and relationships with cardinality constraints.

Q2IntermediateQuiz

A library system has Books, Members, and Loans. A member can borrow many books; a book can be borrowed many times by different members. Model this with an ER diagram including participation constraints and the Loan as an associative entity with date attributes.

Q3IntermediateICA

Explain the difference between total and partial participation. In your university ER diagram, which relationships have total participation? Justify each choice.

Q1AdvancedExam

Design a complete ER diagram for a hospital management system supporting patients, doctors, wards, appointments, prescriptions, and billing. Discuss every design decision including specialisation/generalisation hierarchies, weak entities, and cardinality constraints. Identify any design ambiguities and how you resolved them.

Q2AdvancedProject

Convert the Extended ER (EER) concept of specialisation into a relational schema. Discuss the three conversion strategies (single table, table per subclass, table per concrete class) and analyse when each is appropriate in terms of query performance and data integrity.

Module 02

Relational Model

Q1EasyQuiz

Define: relation, tuple, attribute, domain, degree, and cardinality. Use a concrete example for each.

Q2EasyICA

What is the difference between a primary key, a candidate key, and a foreign key? Give an example of each in a Student-Enrollment schema.

Q3EasyQuiz

State the entity integrity constraint and the referential integrity constraint. What happens if either is violated?

Q1IntermediateQuiz

Convert the following ER diagram components into a relational schema: a many-to-many relationship between Employee(EmpID, Name) and Project(ProjID, Title) with a WorksOn relationship carrying a Hours attribute.

Q2IntermediateICA

A weak entity OrderItem depends on Order. How do you represent this in a relational schema? What is the primary key of OrderItem?

Q1AdvancedExam

Discuss the three referential integrity violation response options: RESTRICT, CASCADE, and SET NULL. For each, give a real-world scenario where it is the most appropriate choice. What are the risks if the wrong option is chosen?

Module 03

Relational Algebra

Q1EasyQuiz

Name the six fundamental relational algebra operations and briefly describe what each does.

Q2EasyICA

Given relation Student(ID, Name, GPA, DeptID), write a relational algebra expression to retrieve the names of all students with GPA > 3.5.

Q3EasyQuiz

What is the difference between a natural join and an equi-join? Give an example where the result differs.

Q1IntermediateQuiz

Given Employee(EmpID, Name, DeptID, Salary) and Department(DeptID, DeptName, ManagerID), write relational algebra expressions for: (a) names of employees in the "CS" department, (b) names of managers, (c) departments with no employees.

Q2IntermediateICA

Explain the division operator in relational algebra. Use it to find students who have enrolled in ALL courses offered by the CS department.

Q3IntermediateQuiz

Show that the intersection operation (∩) is not a fundamental operation — express it using only union and set difference.

Q1AdvancedExam

Relational algebra expressions are not unique for a given query. Write three different relational algebra expressions for "find names of employees who earn more than their manager." Then explain how a query optimizer uses equivalence rules to transform one expression into a more efficient one.

Q2AdvancedExam

Extended relational algebra includes outer joins and aggregation. Express the following using extended RA: "For each department, list the department name and the average salary of its employees. Include departments with no employees, showing NULL for their average."

Module 04

SQL Foundations

Q1EasyICA

Write SQL to create a table Product(ProductID INT PRIMARY KEY, Name VARCHAR(100), Price DECIMAL(10,2), Stock INT NOT NULL). Then insert three rows and retrieve all rows where Price > 50.

Q2EasyQuiz

What is the difference between WHERE and HAVING? When must you use each?

Q3EasyICA

Explain the difference between DELETE, TRUNCATE, and DROP. Which is reversible and which is not?

Q4EasyQuiz

Write SQL to retrieve all students whose names start with "A" and sort them alphabetically. Use the Student(ID, Name, GPA) schema.

Q1IntermediateQuiz

Write SQL for all four join types (INNER, LEFT OUTER, RIGHT OUTER, FULL OUTER) on Employee(EmpID, Name, DeptID) and Department(DeptID, DeptName). Describe what rows appear in each result that would not appear in the others.

Q2IntermediateICA

Use the NULL semantics of SQL to explain: why does NULL = NULL evaluate to UNKNOWN? How does this affect a WHERE clause that filters on a nullable column?

Q1AdvancedExam

A query returns unexpected NULL values after an outer join. Walk through the three-valued logic (TRUE, FALSE, UNKNOWN) to explain why a WHERE dept = 'CS' clause silently drops outer-join NULLs. Rewrite the query to correctly preserve them.

Module 05

SQL Intermediate

Q1EasyICA

Given Orders(OrderID, CustomerID, Amount, OrderDate), write SQL to find the total amount ordered per customer, showing only customers whose total exceeds 1000.

Q2EasyQuiz

What does a correlated subquery do? Give a simple example and explain why it can be slower than a join.

Q1IntermediateQuiz

Write SQL using EXISTS to find all customers who have placed at least one order in the last 30 days. Then rewrite the same query using a JOIN. Which form does the query optimizer prefer and why?

Q2IntermediateICA

Using Employee(EmpID, Name, Salary, DeptID), write SQL to find the second-highest salary in each department. Solve it two ways: once with a subquery and once with DENSE_RANK().

Q3IntermediateQuiz 2

Explain the difference between IN, EXISTS, and ANY/ALL in SQL subqueries. For each, write an example query and state when it is preferred over the others.

Q1AdvancedExam

A manager asks: "Find all employees who earn more than the average salary of their own department." Write this as (a) a correlated subquery, (b) a derived table, and (c) a window function. Compare the readability and likely query plan cost of each approach.

Module 06

SQL Advanced

Q1EasyICA

What is a Common Table Expression (CTE)? Write a CTE that computes total sales per region and then selects only regions with total sales above the average.

Q2EasyQuiz 2

What is the difference between a stored procedure and a trigger in SQL? Give a real-world example where each is appropriate.

Q1IntermediateQuiz 2

Using SalesTransaction(TxnID, SaleDate, Amount, SalespersonID), write SQL with window functions to compute: (a) running total of Amount per salesperson ordered by date, (b) each transaction's rank within its month, (c) the 3-transaction moving average for each salesperson.

Q2IntermediateICA

Write a recursive CTE to list all ancestors of a given employee in an Employee(EmpID, Name, ManagerID) hierarchy table.

Q1AdvancedExam

Design a trigger-based audit system for a banking Account(AccountID, Balance) table. The trigger must log every UPDATE to a separate AuditLog table capturing the old and new balance, the timestamp, and the database user. Discuss the performance implications of row-level versus statement-level triggers for high-throughput systems.

Module 07

Normalization

Q1EasyQuiz 2

Define functional dependency. Give two examples from a university database and identify which is trivial and which is non-trivial.

Q2EasyICA

What anomalies (insertion, update, deletion) can occur in an unnormalized relation? Give a concrete example of each using a StudentCourse(StudentID, StudentName, CourseID, CourseName, Grade) table.

Q3EasyQuiz 2

State the conditions for 1NF, 2NF, 3NF, and BCNF. For each, give a relation that satisfies it but violates the next higher normal form.

Q1IntermediateQuiz 2

Given R(A, B, C, D, E) with FDs: A → B, BC → D, D → E. (a) Find all candidate keys. (b) Determine the normal form of R. (c) Decompose R into BCNF and verify the decomposition is lossless.

Q2IntermediateExam

Using Armstrong's axioms (reflexivity, augmentation, transitivity), derive all FDs implied by the set {A → B, B → C, C → D}. Compute the closure of {A}.

Q1AdvancedExam

BCNF decomposition is always lossless but may not be dependency-preserving. Construct an example where achieving BCNF loses a functional dependency. Show how 3NF decomposition preserves it. Discuss the trade-off a database designer must make.

Q2AdvancedProject

A denormalized table is sometimes preferred in data warehouses. Explain the concept of a "star schema" and argue why 3NF normalization would harm rather than help query performance in an OLAP setting.

Module 08

Storage & Indexing

Q1EasyQuiz 2

What is a B+ tree index? How does it differ from a B-tree? Why do database systems prefer B+ trees?

Q2EasyICA

Explain the difference between a clustered index and a non-clustered index. Can a table have more than one clustered index? Why or why not?

Q3EasyQuiz 2

What is the role of the buffer pool in a DBMS? What happens when a page is "dirty" in the buffer pool?

Q1IntermediateExam

A B+ tree of order 4 has 10,000 records. Estimate the height of the tree and the number of disk accesses needed for (a) a point query, (b) a range query returning 200 records. Compare this to a heap file scan.

Q2IntermediateICA

Explain static hashing and dynamic (extendible) hashing. When does static hashing perform poorly and how does dynamic hashing address it?

Q1AdvancedExam

A high-traffic e-commerce site runs queries like: "find all orders by CustomerID placed between two dates sorted by Amount." Design an indexing strategy (which columns, which index type, clustered or not). Justify your choices considering the trade-off between query speed and write overhead.

Module 09

Query Processing & Transactions

Q1EasyQuiz 2

State the four ACID properties of a database transaction. Give a banking example that shows what goes wrong if each property is violated.

Q2EasyICA

What is a schedule in the context of concurrency control? What is the difference between a serial schedule and a serializable schedule?

Q3EasyQuiz 2

Name three types of read anomalies that can occur without proper isolation. Define each and give an example.

Q1IntermediateExam

Two transactions T1 and T2 both read then update the same account balance. Draw a schedule that results in a lost update. Then show how Two-Phase Locking (2PL) prevents this and what deadlock scenario might arise as a side effect.

Q2IntermediateICA

Explain the four SQL isolation levels: READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ, SERIALIZABLE. For each level, state which anomalies it allows and give a use case where that level is appropriate.

Q1AdvancedExam

Explain the ARIES recovery algorithm (Analysis, Redo, Undo phases). Given a log with COMMIT for T1 but no COMMIT for T2 at crash time, walk through each phase. Why does ARIES use a "no-force, steal" buffer management policy and what does it imply for the log?

Module 10

Modern & AI Data Systems

Q1EasyExam

What is the CAP theorem? For a distributed database, what does it mean to choose CP versus AP? Give a real-world example of each choice.

Q2EasyICA

Explain the difference between a document store (e.g., MongoDB), a key-value store (e.g., Redis), and a column-family store (e.g., Cassandra). Give a use case suited to each.

Q3EasyExam

What is a vector database? How does it differ from a relational database in terms of data representation and query type? Name one commercial vector database.

Q1IntermediateExam

Explain how a RAG (Retrieval Augmented Generation) pipeline works. What role does the vector database play? What are the three failure modes — retrieval miss, hallucination, and context overflow — and how can each be mitigated?

Q2IntermediateProject

Design a schema for storing document embeddings in a vector database for a university knowledge base. What chunking strategy would you use? What metadata would you store alongside each vector? How would you handle document updates?

Q1AdvancedProject

A fintech startup needs to store transaction records (strong consistency required), user preference profiles (flexible schema, fast reads), and a semantic search feature over support tickets. Design a polyglot persistence architecture using three different database systems. Justify each choice and explain how you would maintain consistency across them.
