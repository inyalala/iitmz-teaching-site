Database Management Systems

A theory-first introduction to database systems: data modeling with ER diagrams, the relational model, relational algebra, and SQL from foundations through advanced queries. The course continues with normalization, storage structures, indexing, transaction management, and modern data systems including NoSQL, vector databases, and RAG pipelines. Students complete a semester-long project building a database-backed application. Even Semester 2026.

Learning Outcomes

On successful completion, a student will be able to:

  1. 1 Design and refine entity-relationship diagrams for real-world data requirements, and convert ER schemas to normalized relational schemas.
  2. 2 Write relational algebra expressions for queries involving selection, projection, join, set operations, and division.
  3. 3 Compose correct and efficient SQL queries using joins, subqueries, aggregation, window functions, CTEs, and stored procedures in SQL Server and PostgreSQL.
  4. 4 Apply functional dependency theory and normalization through BCNF and 4NF to eliminate redundancy and anomalies.
  5. 5 Explain how databases store data on disk, and describe B-tree and hash-based index structures and their effect on query performance.
  6. 6 Describe the ACID properties of transactions and explain concurrency control (2PL) and crash recovery mechanisms.
  7. 7 Compare relational, document, key-value, and vector database paradigms, and implement a RAG pipeline over a vector database.

Policies

Late work

Late work is not accepted. Deadlines are fixed and announced in advance; submit what you have by the deadline. No extensions.

Academic integrity

All SQL you submit must reflect your own understanding. Copying another student's queries or allowing your work to be copied is a violation. Using AI to generate SQL and submitting it without understanding is a violation; if you use AI as a debugging aid, declare it.

Attendance

Attendance at lectures and tutorials is expected. Tutorials include in-class activities that cannot be made up.
