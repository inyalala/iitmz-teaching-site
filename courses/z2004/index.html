Learning Outcomes

  1. Design and refine entity-relationship diagrams for real-world data requirements, and convert ER schemas to normalized relational schemas.
  2. Write relational algebra expressions for queries involving selection, projection, join, set operations, and division.
  3. Compose correct and efficient SQL queries using joins, subqueries, aggregation, window functions, CTEs, and stored procedures in SQL Server and PostgreSQL.
  4. Apply functional dependency theory and normalization through BCNF and 4NF to eliminate redundancy and anomalies.
  5. Explain how databases store data on disk, and describe B-tree and hash-based index structures and their effect on query performance.
  6. Describe the ACID properties of transactions and explain concurrency control (2PL) and crash recovery mechanisms.
  7. Compare relational, document, key-value, and vector database models, and implement a RAG pipeline over a vector database.

Policies

Late work
Late work is not accepted. Deadlines are fixed and announced in advance; submit what you have by the deadline. No extensions.
Academic integrity
All SQL you submit must reflect your own understanding. Copying another student's queries or allowing your work to be copied is a violation. Using AI to generate SQL and submitting it without understanding is a violation; if you use AI as a debugging aid, declare it.
Attendance
Attendance at lectures and tutorials is expected. Tutorials include in-class activities that cannot be made up.
