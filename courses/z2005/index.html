Learning Outcomes

  1. Design and implement Python classes using encapsulation, inheritance, and polymorphism, and explain why each data structure in this course is built as a class.
  2. Write, test, and debug Python programs that use functions and recursion.
  3. Implement stacks, queues, linked lists, binary trees, hash tables, and heaps from first principles.
  4. Analyze the running time of an algorithm using big-O notation and justify a structure choice by that analysis.
  5. Implement and compare simple and advanced sorting algorithms.
  6. Apply dynamic programming and greedy strategies to optimization problems.
  7. Represent graphs and apply BFS, DFS, and A* to reachability and shortest-path problems.

Policies

Attendance
Attendance is expected at all lectures and labs. Lab work is done during the lab session and submitted before it ends.
Late work
Late work is not accepted. Deadlines are fixed and announced in advance; submit what you have by the deadline. This applies uniformly: there are no extensions or day-based penalty scales.
Academic integrity
Discussing ideas is encouraged; sharing or copying code is not. Every line you submit must be one you can explain.
Use of AI tools
AI coding assistants may be used to explain concepts and read error messages, not to generate solutions you then submit. The examinations assume you can write these structures yourself.
