# Course Materials

Lecture slides, lab exercises, and reference notebooks for courses taught by
Dr. Innocent Nyalala at IIT Madras Zanzibar. Each session below lists a PDF
(the full lecture notes — read this first), the HTML slide deck shown in
class, and an editable PowerPoint version where applicable.

## Programming and Data Structures (Z2005 / Z5007)

Foundational data structures and algorithms, covering arrays, linked
structures, sorting, trees, hashing, dynamic programming, greedy algorithms,
graphs, and parallel/randomized algorithms, offered to both BS (Z2005) and
MTech (Z5007) students.

- [Course home (Z2005, BS)](courses/z2005/index.html)
- [Course home (Z5007, MTech)](courses/z5007/index.html)

Materials are organized by week and are complete through Week 15 (project
presentations and course review).

## Database Management Systems (Z2004)

Relational data modeling, SQL, normalization, transactions, indexing, and

## Big Data Lab (Z5008)

Hands-on distributed data processing with Hadoop and Spark, covering

## Viewing materials

View HTML slide decks from this site directly, not by downloading the file
and opening it locally — browsers block the scripts the slide navigation
needs when a page is opened from disk rather than served over HTTP(S). PDF
and PPTX downloads are unaffected and safe to use offline.

More courses and materials are added as they are prepared.
